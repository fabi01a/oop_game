# oop_game
"Phrase Hunter" - A browser-based, word guessing game that uses JavaScript and OOP to select a random, hidden phrase.
A player tries to guess the phrase by selecting individual letters from an onscreen keyboard. Can the player guess the
phrase before they run out of attempts?
