# oop_game
"Phrase Hunter" - A browser-based, word guessing game that uses JavaScript and OOP to select a random, hidden phrase.
A player has 5 tries to guess the phrase by selecting individual letters from an onscreen keyboard. Can the player guess the
phrase before they run out of attempts?

## Features
- **Interactive Word-Guessing Game:** Players guess letters to reveal a hidden phrase.
- **Object-Oriented Design:** Uses JavaScript ES6 classes (`Game` and `Phrase`) to organize game logic and functionality.
- **Dynamic On-Screen Keyboard:** Players select letters using an interactive keyboard that updates after each guess.
- **Real-Time Phrase Updates:** Correct guesses reveal matching letters in the hidden phrase.
- **Life Tracking:** Players have five lives, represented by heart icons that update after incorrect guesses.
- **Win/Loss Detection:** Automatically determines when a player completes the phrase or runs out of lives.
- **Game Reset:** Players can start a new game without refreshing the browser.
- **DOM Manipulation:** Dynamically updates the game board, keyboard, and result screens using vanilla JavaScript.
